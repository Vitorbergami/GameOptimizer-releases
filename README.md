# Game Optimizer — Releases

Instaladores publicados do [Game Optimizer](https://vitorbergami.github.io/GameOptimizer/) — otimizador de desempenho para jogos no Windows.

Este repositório contém **só os instaladores**, não o código-fonte (que fica num repositório privado). Baixe a versão mais recente na aba [Releases](https://github.com/Vitorbergami/GameOptimizer-releases/releases/latest).

## Requisitos

Windows 10 ou 11 (x64).
